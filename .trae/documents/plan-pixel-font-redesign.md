# 计划:像素字体编辑器重构 + 26 字母重新设计

## Context(为什么做)

用户报告的 bug 已修(白名单校验),但反馈了 3 个进一步需求:

1. **当前加新字符体验差**:`_add_letter` 总是挑 A-Z 里"第一个没用过的",用户无法主动选字母
2. **没有默认 26 字母的像素图**:用户必须从空白网格开始,毫无参考
3. **代码逻辑需要整理**:`pixel_font_editor.py` 有 936 行,两个类(PixelFontEditor + _PixelFontEditorPanel)大量重复代码;其中 `PixelFontEditor`(QDialog)是死代码(只有 standalone `__main__` 入口在用)

**预期产出**:
- 主题页面编辑器点 + 后弹一个 5x6 字母选择器,可任意选 A-Z
- 内置 26 个字母的硬朗风格默认像素图(可作为编辑起点)
- 代码大幅瘦身,删除死代码,消除重复

---

## 设计决策(已与用户确认)

| 维度 | 选择 |
|---|---|
| 字体风格 | **硬朗直线,无弯曲弧线** — 几何切角风格(用户原话) |
| 字模尺寸 | **16x20**(与现有 R/E/L/I/C 同尺寸,含底部装饰行) |
| 选字 UI | **5x6 弹窗**(点 + 后弹 QDialog,5 列 6 行) |
| 默认字典 | **预填 A-Z 全部 26 字母** 到 `_DEFAULT_FONT`(覆盖原 5 字母) |

⚠️ **副作用提示**:`_DEFAULT_FONT` 现有 5 个字母(R/E/L/I/C)会被新设计覆盖。**启动画面的"RELIC"字样会变样**(从粗实心 → 硬朗几何风)。如果用户希望保留现有 5 字母的 splash 效果,需要我同时保留旧版作为 `splash_v2`(但这超出本次范围)。

### 2.1 `core/state/pixel_font.py` — L-State 纯数据层

**改动**:

1. **删除旧的 `_DEFAULT_FONT`** 字典(5 字母)
2. **新增 26 字母 ASCII art 常量**(`_LETTER_ART_A` 到 `_LETTER_ART_Z`)
3. **新增解析函数** `_parse_letter_art(art: str) -> list[list[int]]`:
   - 拆分多行字符串为 14 行
   - 每行映射 `.` → 0, `#` → 1
   - 不足 16 字符的右边补 0
   - 不足 14 行的底部补 0 行
   - 末尾追加 6 行装饰(3 空 + 1 全 1 + 1 空 + 1 全 1)
4. **重建 `_DEFAULT_FONT`** = `{ch: _parse_letter_art(_LETTER_ART_X) for ch in "ABCDEFGHIJKLMNOPQRSTUVWXYZ"}`
5. **`_validate()` 已修,不动**

**关键代码**:
```python
def _parse_letter_art(art: str) -> list[list[int]]:
    """ASCII art 字符串 → 16x20 像素网格。

    格式: 16 字符宽, 14 行高(实际字体区);末尾自动追加 6 行底部装饰
    (3 空行 + 1 全填充 + 1 空行 + 1 全填充),总高度 20。
    """
    lines = [ln for ln in art.strip().splitlines() if ln]
    grid: list[list[int]] = []
    for ln in lines:
        row = [1 if c == "#" else 0 for c in ln[:16]]
        # 行宽不足 16 时右边补 0
        row += [0] * (16 - len(row))
        grid.append(row)
    # 行数不足 14 时底部补 0 行
    while len(grid) < 14:
        grid.append([0] * 16)
    # 只取前 14 行(防超出)
    grid = grid[:14]
    # 追加底部装饰: 3 空 + 1 全 1 + 1 空 + 1 全 1
    grid.append([0] * 16)  # row 14
    grid.append([0] * 16)  # row 15
    grid.append([0] * 16)  # row 16
    grid.append([1] * 16)  # row 17
    grid.append([0] * 16)  # row 18
    grid.append([1] * 16)  # row 19
    return grid


_DEFAULT_FONT: dict[str, list[list[int]]] = {
    ch: _parse_letter_art(art)
    for ch, art in {
        "A": _LETTER_ART_A, "B": _LETTER_ART_B, ... "Z": _LETTER_ART_Z,
    }.items()
}
```

```python
class LetterPickerDialog(QDialog):
    """字母选择对话框 — 5x6 网格,26 字母。"""

    def __init__(self, existing: set[str], parent=None):
        QDialog.__init__(self, parent)
        self.setWindowTitle("选择字母")
        self.setModal(True)
        self._selected: str | None = None
        self._existing = set(existing)

        layout = QVBoxLayout(self)
        layout.setContentsMargins(16, 16, 16, 16)
        layout.setSpacing(12)

        title = QLabel("选择要添加的字母")
        title.setStyleSheet("font-weight: bold; font-size: 14px;")
        layout.addWidget(title)

        # 5x6 网格
        grid = QGridLayout()
        grid.setSpacing(6)
        for i, ch in enumerate("ABCDEFGHIJKLMNOPQRSTUVWXYZ"):
            row, col = divmod(i, 5)
            btn = QPushButton(ch)
            btn.setFixedSize(44, 44)
            btn.setCursor(Qt.CursorShape.PointingHandCursor)
            if ch in self._existing:
                # 已用:灰显 + 禁用(但仍可见,提示已存在)
                btn.setEnabled(False)
                btn.setStyleSheet(f"opacity: 0.3; color: {_tc('text.disabled')};")
                btn.setToolTip(f"{ch} 已存在")
            else:
                btn.setToolTip(f"添加字母 {ch}")
                btn.clicked.connect(lambda checked, c=ch: self._on_pick(c))
            grid.addWidget(btn, row, col)
        layout.addLayout(grid)

        # 取消按钮
        btn_row = QHBoxLayout()
        btn_row.addStretch()
        btn_cancel = QPushButton("取消")
        btn_cancel.clicked.connect(self.reject)
        btn_row.addWidget(btn_cancel)
        layout.addLayout(btn_row)

    def _on_pick(self, ch: str) -> None:
        self._selected = ch
        self.accept()

    def selected_letter(self) -> str | None:
        return self._selected
```

**`_add_letter` 改写**:
```python
def _add_letter(self) -> None:
    """弹出字母选择器,用户选一个字母添加(若已存在则直接切换)。"""
    dlg = LetterPickerDialog(set(self._font_data.keys()), self)
    if dlg.exec() == QDialog.DialogCode.Accepted:
        ch = dlg.selected_letter()
        if not ch:
            return
        if ch not in self._font_data:
            # 新字母:初始化默认网格(从 _DEFAULT_FONT 取)
            default_grid = _PIXEL_FONT.get(ch, [])
            if default_grid:
                self._font_data[ch] = [row[:] for row in default_grid]
            else:
                # 兜底:空 16x20
                self._font_data[ch] = [[0] * 16 for _ in range(20)]
        self._rebuild_char_buttons()
        self._load_letter(ch)
```

### 4.3 splash 副作用
`_DEFAULT_FONT` 改动后,**RELIC 启动画面会从"粗实心" → "硬朗几何"**。这是用户接受的范围(他说"完全重新设计")。如需保留旧 splash,需要单独做一个 `_LEGACY_FONT` 常量给 splash 用,本次不做。

### 4.4 26 字母 art 占用空间
每个字母 14 行,平均 13 字符,约 200 字节/字母。26 × 200 = ~5 KB。完全可以接受。
