# 沉浸模式卡片底色自定义切换 — 实现计划

## Context

**需求**: 在「主题换肤页面」的全局沉浸模式区块,新增"卡片底色"二选一切换 — 用户可在「主题色」(默认,沿用 token 解析的当前主题底色) 和「纯黑 #000000」之间切换,沉浸模式开启时,导航/卡片/面板的底色按所选预设呈现。

**为什么**: 现在沉浸模式开启后底色一律走 token 主题色(如 cyberpunk 的 #0E0E24),有些用户希望在沉浸时让卡片更"黑"更纯粹,与壁纸形成更强对比。提供两个预设即可满足这两种审美。

**用户决策**(已确认):
- 「黑色」预设 = 纯黑 `#000000`(用现有 token `surface.overlay`)
- UI 形式 = 两个互斥 CyberButton(蓝描边 off / 黄实心 on),与「仅钢铁之路 / 仅普通」风格一致

**作用范围**(仅沉浸模式开启时生效;关闭沉浸时这两个按钮的选中状态保留但不影响绘制):
- 卡片 `CyberCard.paintEvent` 底色 token `components.card.bg`
- 面板 `CyberPanel.paintEvent` 底色 token `components.panel.bg`
- 导航标签 `CyberWidgetMixin._draw_nav_tab` 底色 token `nav.bg`
- AppShell `navContainer` QSS 底色 token `alias.bg.base`

边框、切角装饰、左侧竖条、文字、输入控件**不折减**(沿用既有约束)。

## 实现步骤

### 1. 数据层 — `core/services/ui_prefs.py`

- `_DEFAULT_BACKGROUND` 字典加字段: `"immersive_color": "theme"` (合法值 `"theme"` / `"black"`)。
- `load_background_prefs()` 加解析: 只接受字符串 `"theme"` 或 `"black"`,非法值回退 `"theme"`。
- `save_background_prefs()` 加参数 `immersive_color: str = "theme"` 并写入 JSON。

### 2. Service 层 — `core/services/background_service.py`

- 加字段 `self._immersive_color: str = "theme"`。
- 加信号 `immersive_color_changed = Signal(str)`。
- 加方法 `set_immersive_color(mode: str)`: 钳制为 `"theme"`/`"black"`,无变化直接 return,更新字段 → 发 `immersive_color_changed` 信号 → `_persist()`。
- 加 property `immersive_color`。
- `load_on_start()`: 从 prefs 读 `immersive_color`,初始化后发 `immersive_color_changed` 信号(供 AppShell 应用到控件层 + navContainer)。
- `_persist()`: 调 `save_background_prefs` 时多传 `immersive_color=self._immersive_color`。
- `get_state()` 加 `immersive_color`。

### 3. Widget 层 — `core/widgets/base.py` (CyberWidgetMixin)

新增类级状态 + helper:

```python
# 类级:沉浸黑色模式开关(类级保证懒创建的新卡片自动继承)
_cyber_immersive_color_override: Optional["QColor"] = None  # None=用 token 原色;非 None=覆写 RGB

@classmethod
def set_immersive_color_mode(cls, mode: str) -> None:
    """设置沉浸模式卡片底色预设。
    
    mode="theme" → 不覆写,沿用 token 原色(默认)
    mode="black" → 沉浸时覆写为纯黑(用 surface.overlay token,失败兜底 QColor(0,0,0))
    """
    if mode == "black":
        # 复用 token,不硬编码;失败时纯黑兜底
        from PySide6.QtGui import QColor
        c = QColor(0, 0, 0)
        try:
            from core.tokens.manager import TokenManager
            v = TokenManager.instance().get("surface.overlay")
            if v:
                tc = QColor(v)
                if tc.isValid():
                    c = tc
        except Exception:
            pass
        cls._cyber_immersive_color_override = c
    else:
        cls._cyber_immersive_color_override = None
```

新增底色解析 helper(让三处底色绘制走统一入口):

```python
def _cyber_immersive_resolve_bg(self, key: str, alpha: float) -> "QColor":
    """从 token 取底色 → 沉浸黑色模式时覆写 RGB(保留 alpha) → 折减 alpha。
    
    Args:
        key: 颜色 token 路径(如 "components.card.bg")
        alpha: 非沉浸时的目标 alpha(如 0.85)
    
    Returns:
        最终 QColor(已应用 alpha 折减)
    """
    from PySide6.QtGui import QColor
    color = self.token_color(key)
    if (
        self._cyber_immersive
        and self._cyber_immersive_color_override is not None
    ):
        o = self._cyber_immersive_color_override
        # 覆写 RGB,保留原 alpha
        color = QColor(o.red(), o.green(), o.blue(), color.alpha())
    color.setAlphaF(self._cyber_immersive_alpha(alpha))
    return color
```

#### 4c. `core/widgets/base.py` `_draw_nav_tab` L486

`bg_color_str` 是字符串来源,需要直接取 QColor 并在沉浸黑色模式下覆写。最干净的做法:让 `_draw_nav_tab` 内部把 `bg_color = QColor(bg_color_str)` 改成:

```python

```

新增 helper(只在 base.py 内部用,带 `_cyber_` 前缀):

```python
def _cyber_resolve_nav_bg_color(self, fallback_str: str) -> "QColor":
    """导航标签底色:沉浸黑色模式时覆写 RGB,保留原 alpha 默认 255。"""
    from PySide6.QtGui import QColor
    color = QColor(fallback_str)
    if (
        self._cyber_immersive
        and self._cyber_immersive_color_override is not None
    ):
        o = self._cyber_immersive_color_override
        color = QColor(o.red(), o.green(), o.blue())
    return color
```

后续 L562-L575 的 `setAlphaF` 调用照旧,折减逻辑不变。

### 5. AppShell — `core/app_shell.py`

- 信号连接: `bg_svc.immersive_color_changed.connect(self._on_immersive_color_changed)`(在已有 `immersive_changed` 连接旁边)。
- 新增槽 `_on_immersive_color_changed(mode: str)`:
  - 调 `CyberWidgetMixin.set_immersive_color_mode(mode)`
  - 调 `self._apply_nav_container_style(bg_svc.immersive, bg_svc.immersive_strength, mode)`
  - 遍历 `QApplication.allWidgets()` 触发 `update()`
- 扩展 `_apply_nav_container_style` 签名为 `(immersive, strength, color_mode="theme")`:
  - 沉浸时若 `color_mode == "black"`, 把底色 RGB 改为 `QColor(0,0,0)`(或直接用 token `surface.overlay`)
  - 原 alpha 折减逻辑不变
- `_on_immersive_changed(enabled, strength)` 也要调一次新版 `_apply_nav_container_style`,把当前 `bg_svc.immersive_color` 传进去(开关变化时 navContainer 也要按当前 color_mode 应用)。
- 启动初始化处: `bg_svc.load_on_start()` 后调一次 `CyberWidgetMixin.set_immersive_color_mode(bg_svc.immersive_color)`。

## 验证

1. **回归测试**: `pytest`(项目根目录),应仍跑通 144 项。
2. **启动软件**: 首次启动默认 `immersive_color="theme"`,开启沉浸模式 → 卡片底色仍是当前主题色。
3. **切换纯黑**: 点"纯黑"按钮 → 该按钮变黄实心、"主题色"变蓝描边 → 卡片/面板/导航栏底色立即变黑(沉浸强度决定 alpha)。
4. **重启软件**: 选择应保留(`ui_prefs.json` 持久化)。
5. **关闭沉浸**: 卡片恢复正常 token 底色,但两个按钮选中状态保留(`on_enter` 同步)。
6. **主题预设切换**: 切到 Daylight 后,"主题色"按钮显示 Daylight 底色;"纯黑"按钮始终显示纯黑。
7. **控制台日志**: 不应有 token 缺失警告(全部走 `_cyber_immersive_resolve_bg` 内置兜底)。
