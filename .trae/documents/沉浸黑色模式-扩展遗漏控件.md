# 沉浸黑色模式 · 扩展遗漏控件统一接入

## Context

上一轮已完成「沉浸底色预设切换」(theme / black),但只在 CyberCard / CyberPanel / 导航标签三处接入了底色覆写。用户实测发现以下页面仍有大量「块状底色控件」没跟随黑色切换,需要统一接入:

- **数据总览页**:数据库状态 box、数据展示 box(统计卡片)、操作日志的日志显示区
- **物品查询页**:输入框
- **辅助触发器页**:触发器名称输入框、触发方式下拉菜单、执行动作下拉菜单、键位设置、延迟 QSpinBox、鼠标移动坐标 label
- **CD 辅助显示页**:时间设定框 QDoubleSpinBox

目标:沉浸黑色模式开启时,上述控件的「底色」也覆写为纯黑(沿用现有 `_cyber_immersive_resolve_bg` / `_cyber_immersive_color_override` 机制),用户切回主题色时还原。

## 接入分两类

### A 类:paintEvent 改调 helper(继承 CyberWidgetMixin 的自绘控件)

| 控件 | 文件:行号 | 当前取色 | 改造点 |
|---|---|---|---|
| `CyberLineEdit` | `core/widgets/line_edit.py` L108-L122 | `token_color("components.input.bg")` + 状态 setAlphaF | 三态分支(normal/hover/focused)各调 `_cyber_immersive_resolve_bg`,focused 用 `semantic.state.focused.bg` token |
| `CyberComboBox` 本体 | `core/widgets/combo_box.py` L136-L150 | 同上 | 同 CyberLineEdit |
| `CyberLogViewer` 外框 | `core/widgets/log_viewer.py` L300-L303 | `token_color("components.panel.bg")` + setAlphaF(opacity) | 改调 `_cyber_immersive_resolve_bg("components.panel.bg", opacity)` |
| `ChamferedFrame` | `core/widgets/stat_card.py` L72-L74 | `token_color("components.card.bg")` + setAlphaF(0.85) | 改调 `_cyber_immersive_resolve_bg("components.card.bg", 0.85)` |
| `StatCard` | `core/widgets/stat_card.py` L121-L123 | `token_color("bg.base")` + setAlphaF(0.85) | 改调 `_cyber_immersive_resolve_bg("bg.base", 0.85)` |
| `HotkeyEdit` | `core/widgets/hotkey_edit.py` L165-L215 | `_state_colors` 返回三态 QColor,用 `components.input.bg` / `alias.bg.base` | 改 `_state_colors` 返回值,沉浸黑色模式下用 helper 覆写 RGB 保留 alpha |

A 类改动一行/几行,直接生效,paintEvent 每次重绘自动应用最新沉浸状态。**复用现有 `_cyber_immersive_resolve_bg`**,无需新增 helper。

### B 类:QSS 字符串里的 background-color 需覆写

QSS 字符串只在 `__init__` / `_apply_xxx_style` 里设一次,沉浸模式切换时不会自动重设。需要:

1. **`CyberWidgetMixin` 新增 helper**(`core/widgets/base.py`):
   ```python
   def _cyber_immersive_resolve_token_str(self, key: str, alpha: float = 1.0) -> str:
       """返回沉浸黑色模式覆写后的颜色 hex 字符串(QSS 用)。
       非沉浸/主题色模式:返回 token 原值;
       沉浸黑色模式:返回纯黑 RGB(保留 alpha 比例折减)。
       """
   ```
   复用 `_cyber_immersive_color_override` + `_cyber_immersive_alpha`,返回 `QColor.name(QColor.NameFormat.Argb8)` 等可被 QSS 解析的字符串。

2. **每个 B 类控件加一个 `cyber_refresh_immersive_style()` 公共方法**,重新构造并 setStyleSheet。涉及:
   - `CyberComboBox._apply_popup_style()`(新拆出 __init__ 里的 QSS 构造代码)+ `cyber_refresh_immersive_style()` 调它
   - `CyberLogViewer._apply_text_style()`(已存在)+ `cyber_refresh_immersive_style()` 调它
   - `TriggersPage._apply_form_style()`(已存在)+ `cyber_refresh_immersive_style()` 遍历 `_trigger_card_widgets` 里所有 `delay_spin` 和 `move_coord_label` 重新调用
   - `CdAssistPage._apply_spin_style()`(已存在)+ `cyber_refresh_immersive_style()` 遍历 `self._duration_spins` 和 `self._reminder_spins` 重新调用
   - `move_coord_label` 的 QSS 是动态写在 `_build_action_row` 里(L499-L503),抽出到一个 `_apply_move_coord_style(label)` 方法,在 `cyber_refresh_immersive_style` 里遍历调用

3. **`AppShell._on_immersive_color_changed` 槽扩展**(`core/app_shell.py`):
   切换沉浸颜色模式时,除了现有 `QApplication.allWidgets()` 遍历调 `update()`,还要对有 `cyber_refresh_immersive_style` 方法的控件调用一次:
   ```python
   for w in QApplication.allWidgets():
       if hasattr(w, "cyber_refresh_immersive_style"):
           try: w.cyber_refresh_immersive_style()
           except Exception: pass
   ```
   Page 也是 QWidget,会自动被遍历到,`TriggersPage` / `CdAssistPage` 实现 `cyber_refresh_immersive_style` 即可。

## 不接入的范围(确认)

- 文字颜色、边框颜色、装饰线、图标颜色:**不接入**(沉浸黑色模式只覆写底色,与 CyberCard / CyberPanel 现有行为一致)
- 数据总览页的 `_status_indicator`(状态圆点)、`_db_info_label`(小信息文字)、`_update_status_label` 等小 QLabel 的 transparent 背景:**不接入**(无块状底色)
- 物品查询页的 tooltip 容器(`_create_tooltip_widget`):**不接入**(运行时动态创建,且用 `components.card.bg` 已接入)
- 操作日志的清空按钮、计数 label:**不接入**(transparent 背景)
- CyberButton / CyberToggleSwitch / CyberCard / CyberPanel 等**已接入**的控件:无需改动

## 验证方式

1. 启动软件,进入「主题换肤」页,打开沉浸模式 + 选「纯黑」底色
2. 切到以下页面验证底色变黑、文字 / 边框 / 装饰线颜色不变:
   - 数据总览:数据库状态 box / 6 个统计卡片 / 操作日志显示区
   - 物品查询:搜索输入框
   - 辅助触发器:触发器名称输入框 / 触发方式下拉(本体 + 弹窗) / 执行动作下拉(本体 + 弹窗) / 键位设置框 / 延迟 QSpinBox / 鼠标移动坐标 label
   - CD 辅助显示:时长 QDoubleSpinBox / 提醒 QDoubleSpinBox
3. 切回「主题色」底色,验证所有控件底色还原
4. 关闭沉浸模式,验证所有控件底色回到原 token 主题色
5. 运行 `python -m pytest -q`(dxcam 沙箱报错属正常,不影响测试)
